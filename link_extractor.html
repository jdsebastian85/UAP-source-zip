Large files. Google puts a virus-scan interstitial in front of anything big, so a plain curl or wget on a direct-download URL returns an HTML page instead of the video. gdown handles the interstitial. Use the curl script only for small files.
On a phone. Use the open link, not download — mobile browsers handle 100 MB+ video badly. The Drive app plays it without pulling it down.
Permissions. Links only work while the Drive item stays shared. Anyone you hand this list to needs access, and the list stops working if the account changes.
